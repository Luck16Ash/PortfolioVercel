# Portfólio — Luca D’Agostino

Site estático responsivo feito com HTML, CSS e JavaScript, preparado para deploy na Vercel.

## Executar localmente
Abra `index.html` no navegador. Para uma experiência mais próxima de um servidor web, use a extensão Live Server do VS Code.

## Publicar na Vercel
1. Crie um repositório no GitHub e envie os arquivos desta pasta.
2. Entre em https://vercel.com/ e faça login com GitHub.
3. Selecione **Add New → Project** e importe o repositório.
4. Como é um site estático, deixe o Framework Preset como **Other**.
5. Deixe **Build Command** e **Output Directory** vazios e clique em **Deploy**.

## Antes de publicar
- Confirme os links dos repositórios e da plataforma.
- Adicione seu currículo em PDF se quiser habilitar um botão de download.
- Revise as tecnologias e descrições para refletirem exatamente sua contribuição em cada projeto.
